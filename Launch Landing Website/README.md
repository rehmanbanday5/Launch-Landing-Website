# Launch Landing Page

This repository contains a **simple landing page website** built using **HTML, CSS, and Bootstrap**, inspired by a **Colorlib template**. The page is a **static layout** designed for showcasing digital products or services with sections like Features, Pricing, and Contact.

---

## 🌟 Features

- **Landing Page Layout**: Hero section, Features, Pricing, and Contact sections.  
- **Static Design**: Simple HTML and CSS implementation without backend functionality.  
- **Basic Interactivity**: Buttons and links navigate within the page.  
- **Clean Structure**: Easy to understand and customize for personal or educational projects.  

---

## 🛠 Technologies Used

- **HTML5**: Structure of the landing page.  
- **CSS3**: Styling and layout.  
- **Bootstrap 5**: Grid system and components for layout and design.
